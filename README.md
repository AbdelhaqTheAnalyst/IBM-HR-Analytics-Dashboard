# IBM Employee Attrition & Workforce Analytics Dashboard (Excel)

## 📌 Project Overview
This project delivers a comprehensive, interactive, and data-driven Human Resources (HR) Analytics Dashboard built entirely in **Microsoft Excel**. Using the official IBM HR Analytics dataset, the project identifies key drivers behind employee attrition, uncovers workforce satisfaction trends, and provides actionable insights to help corporate leadership improve employee retention and optimize management strategies.

## 📊 Key Performance Indicators (KPIs)
* **Total Employees:** 1,470
* **Attrition Rate:** 16.12% 
* **Average Monthly Salary:** $6,503
* **Average Tenure at Company:** 7 Years

## 🛠️ Data Architecture & Analytical Features
* **Advanced Data Cleaning (Power Query):** Streamlined the raw dataset containing 35 columns by filtering anomalies, updating data types, and removing redundant single-value parameters (`EmployeeCount`, `Over18`, `StandardHours`) to optimize processing performance.
* **Complex Data Modeling:** Established background analytical matrices using complex Excel functions and dynamic formulas (`XLOOKUP`, `SUMIFS`, `AVERAGE`).
* **Dynamic Slicers (Fully Interactive):** Integrated advanced multi-chart filtering connections allowing corporate viewers to segment the entire dashboard dynamically by **Gender**, **Marital Status**, and **Overtime Work** with a single click.

## 📈 Visualizations Included
1. **Attrition Analysis by Department (Clustered Column Chart):** Tracks which core departments experience the highest employee turnover.
2. **Employee Turnover by Job Role (Horizontal Bar Chart):** Pinpoints precise high-risk job titles with the greatest attrition numbers.
3. **Impact of Overtime on Attrition (Doughnut Chart):** Illustrates the direct correlation between excessive overtime workloads and voluntary resignations.
4. **Distribution of Attrition by Job Satisfaction (Treemap Chart):** Breaks down the volume of departing staff across 4 distinct levels of job happiness to measure organizational health.

## 🚀 How to Explore
1. Clone or download the `IBM_HR_Analytics_Dashboard.xlsx` file from this repository.
2. Open it using Microsoft Excel (Desktop App recommended for full Power Query capabilities).
3. Interact with the vertical **Slicers** on the left to filter the metrics instantly.
